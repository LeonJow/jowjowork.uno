个人主页 v1

2021静态站 · 入门

一、起点

2021 年，我花了两个周末搭出了第一个能访问的页面。那会儿连 Git 都不会，照着网上教程把 index.html 拖到 GitHub Pages 里，看到域名真的能打开，兴奋了半天。

整个站只有一页，黑色背景、几行居中文字、一个邮箱链接。以今天的眼光看非常简陋，但它是我第一次把一个想法变成别人能打开的网页。

二、学到的东西

这次经历让我搞懂了三件事：第一，静态托管不需要服务器，GitHub Pages 免费就能用；第二，域名解析没有想象中复杂，CNAME 文件一放就行；第三，写 HTML/CSS 其实比我想象中好玩。

也踩了坑：在本地看着好好的布局，传到线上字体全变了；后来才知道是系统字体和网页字体不是一回事。

三、它为什么重要

如果没有这个粗糙的 v1，后面就不会有 v2、v3，也不会有现在的 JowJo。它提醒我：先把东西做出来，再慢慢改好看。

现在它下线了，但文件夹还留着，偶尔翻出来看看，能想起当时那种「我也会做网站了」的心情。
