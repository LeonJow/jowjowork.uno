不会写代码的文科生，怎么做出了 2.3 万星开源项目

2026-08-08张咋啦约 8 分钟

一、文科生最好的时代

张咋啦（Zara Zhang）的背景很「文科」：哈佛心理学本科、当过 The Information 记者、做过真格和 GGV 的投资人，现在是硅谷的 AI 产品经理。

她给过一句很提气的话：

文科生最好的时代——技术浪潮一来，一切归零，所有人回到同一起跑线。

二、不会写代码，靠 Coding Agent 做出 2.3 万星项目

张咋啦自称不会写代码，但她用 Coding Agent 做出了开源项目 frontend-slides，拿了 2.3 万星。她的 GitHub 自我介绍写着：code is a medium of self-expression（代码是自我表达的方式）。

她的方法论就四个字：learn by doing。她常说「先把手弄脏」——不要等学会了再开始，而是先开始，在做的过程里学会。

三、定位是折腾出来的，不是想出来的

张咋啦在小红书一年时间从 2 万涨到近 19 万粉，发了近 500 篇内容。她的经验很朴素：定位是折腾出来的，不是想出来的。

「你不需要任何人的许可」——她做学习工具 LongCut、做信息聚合项目 Follow Builders，都是先做了再说。AI 时代做东西的成本前所未有地低，唯一缺的是「开始」。

四、文科生第一次用 Coding Agent 的 prompt（可以复制）

如果你也想试试「不会写代码但做出东西」，可以照这个套路问 AI：

我是一个不会写代码的产品经理。
我想做一个网页：＜描述你想要的东西，越具体越好＞

请你：
1. 先告诉我这个页面需要哪些文件；
2. 帮我写完整的 HTML / CSS / JS；
3. 写完后告诉我怎么在浏览器里打开；
4. 每解释一步都用大白话，不要用术语。

描述得越具体，结果越好。先做个丑的能用的，再慢慢改。

五、「活人感」：AI 时代最稀缺的东西

张咋啦判断「2025 是行动的一年，看视频和学习其实是一种懒惰」。

她还提出了一个很火的词——「活人感」：社交媒体上全是 AI 写的内容，一看就不真诚。所以未来的竞争力不是「写得像 AI」，而是「写得像活人」。

她的主张：Follow Builders, Not Influencers——去关注那些真正做出东西的人，而不是只会说的人。AI 应该帮人表达，而不是替人表达。
