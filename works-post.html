LUUC 子项目复盘

2026-07个人主页设计 + 前端

LUUC 是我练手的一个独立个人主页：带留言板、相册和轻量 CMS，部署在 Netlify。这里复盘一下从设计到上线的关键决定。

一、为什么单独做一个站

主站 jowjowork.uno 走 GitHub Pages、纯静态；而这个实验想试试 Netlify 的表单与函数能力，所以单独起了一个仓库，互不干扰。

二、结构怎么拆

首页只放「一句话定位 + 几个入口」，把留言板和相册拆成独立页面，加载更快，也更好维护。

小站点最怕什么都塞首页，入口清晰比信息多更重要。

三、上线后的取舍

Netlify 的表单收集确实省事，但它和主站的部署方式不一致。后续如果要并入主站，得统一成一套工作流。
