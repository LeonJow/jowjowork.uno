信息流一键摘要 Skill

v1.2自动化可复用

这个 Skill 接收你当天收集的内容（链接、截图、剪贴文本），自动产出结构化摘要并打标签。下面是实现思路与用法。

一、它解决什么

每天信息太多，手动整理太慢。这个 Skill 把「收集 → 摘要 → 归档」三步合并成一次调用。

二、怎么用

把待整理内容贴进来，调用即可。核心提示词结构如下：

角色：信息整理助手
输入：用户提供的原始内容
输出：标题 / 一句话摘要 / 3 个标签 / 是否值得长期保存

三、进阶：定时推送

配合定时任务，每天晚上自动跑一遍，第二天早上直接看结果。配合 ai-post.html 里的工作流效果更好。

四、下载

完整 Skill 文件放在 skills.html 列表里，点进去即可复制使用。
