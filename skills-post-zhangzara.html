文科生 Coding 法

整理自 张咋啦 的 AI 经验可一键复制

一、它解决什么

「我不会写代码」是很多人不用 AI 做东西的最大借口。张咋啦（Zara Zhang）恰好反着来：她自称不会写代码，却靠 Coding Agent 做出了 2.3 万星的开源项目。

她的方法论四个字：learn by doing，先把手弄脏。

二、怎么用（可以复制）

我是一个不会写代码的产品经理。
我想做一个网页：＜描述你想要的东西，越具体越好＞

请你：
1. 先告诉我这个页面需要哪些文件；
2. 帮我写完整的 HTML / CSS / JS；
3. 写完后告诉我怎么在浏览器里打开；
4. 每解释一步都用大白话，不要用术语。

三、迭代流程

1. 把需求拆成最小的一步；2. 让 AI 写出来；3. 在浏览器里看效果；4. 提修改意见；5. 循环。

你当「产品经理」，AI 当「程序员」——你负责想清楚要什么，AI 负责把它做出来。描述得越具体，结果越好；先做丑的能用的，再慢慢改。

四、背后的故事

张咋啦还说过「定位是折腾出来的，不是想出来的」「你不需要任何人的许可」。完整思路见：不会写代码的文科生，怎么做出了 2.3 万星开源项目 →
